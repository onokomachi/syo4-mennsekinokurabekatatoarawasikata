# 設計書：めんせきランド（小4 算数「面積のくらべ方と表し方」）

## 1. 一次資料（単元の中身）
- 教科書: 東京書籍『新しい算数4下』「12. 面積のくらべ方と表し方」（p.58〜75）。
  1cm²の方眼で面積を表す／長方形・正方形の面積の公式／m²・km²・a・ha と単位の関係／面積の量感と単位えらび／
  長方形の1辺を求める／複合図形の面積（分ける・ひく）／まわりの長さが同じ長方形の面積の変わり方。
- 紙の単元テスト: 新学社 4年東 下巻「12. 面積のくらべ方と表し方」（表＝知識・技能100点、裏＝思考・判断・表現50点、いかそう算数＝参考）。
  学年のまとめ（大問12・コの字形の面積）も参考にした。

## 3. 誤概念 → 誤答診断（ひとこと）
| 誤概念 | 典型誤答 | どこで揺さぶるか |
|---|---|---|
| 面積なのに まわりの長さを求める／cm と cm² を区別しない | (たて+横)×2、「15cm」 | 答えの診断・`formula-unit`・`eh-perim` |
| ななめ半分の三角を 1cm² と数える | 全部＋三角の数 | `grid-half`・`eh-half` |
| 1m²＝100cm²、1km²＝1000m² | k×100、k×1000 | `unit-m2`・`unit-relation`・`eh-conv` |
| 1a＝10m²、1ha＝100m²・10a | 1けた・2けたずれ | `unit-aha`・`unit-convert`・`eh-aha` |
| 単位をそろえずにかける | 400×2＝800m² | `calc-mixunit`（先に「400cm＝□m」の段）・`eh-unit` |
| 複合図形の、書いていない辺を読みまちがえる | 全体のたてを使う | `comp-split`・`comp-which`・`eh-comp` |
| □×横＝面積 が立てられない | 54×9、54−9 | `side-find`（式→□を求める式→答え の3段） |
| まわりが同じなら面積も同じ | — | `change-*`（表・グラフ・いちばん広いのは正方形） |

## 5. 紙との差
- **式・答 の部分点が無い**: 紙は「式5点・答え5点」。アプリは1問のステップ（式 → 答え）にまとめ、ノーミス完答で10点（大問9は20点）。
- **公式・単位は「書く」でなく「選ぶ」**（大問2・4）。手書きの文字認識をしないため。
- **式は □に数を入れる形**（`□ × □`）。かけ算はじゅんじょを入れかえても正解。大問6③は紙では cm²（400×200）でも正解だが、アプリは m² にそろえる道すじで答えさせる。
- **大問8の表とグラフは別の問題**（まわりの長さが毎回ランダム）。紙は同じ表のデータでグラフをかく。
- **いかそう算数は 50cm の道ではなく 1m・2m の道**（4年はまだ小数のかけ算をしないので、面積を整数にするため）。
- 大問3は 1m²・1km² だけでなく 1〜5 の数でランダムに出す。

## 6. 画面と検査
- 図は `src/lib/shapes.ts` で「長さの単位の座標」として作り、寸法の文字は辺の長さから自動で書く。
- `npm run verify` は、方眼のマス・多角形から面積を計算し直して `figArea`・答えと照合し、寸法の文字が辺の長さと合うかも見る
  （わざと面積を+1 したら検出されることを確かめた）。作図は「正しい形の例」が判定を通るか、何もぬらずに正解にならないかを見る。
